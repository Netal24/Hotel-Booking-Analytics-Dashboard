# Hotel-Booking-Analytics-Dashboard

## 📌 Project Overview
The **Hotel Booking Analytics Dashboard** is an interactive business intelligence project built using Microsoft Power BI to analyze hotel reservation data, customer behavior, booking trends, and cancellation patterns.

This dashboard helps hotels and hospitality businesses make data-driven decisions by identifying:
- Booking trends over time
- Customer booking behavior
- Cancellation risks
- Preferred meal plans
- High-performing market segments
- Revenue-related insights

The project focuses on transforming raw hotel booking data into meaningful visual insights using KPIs, charts, filters, and interactive slicers.

---

## 📊 Key Performance Indicators (KPIs)

The dashboard tracks the following important KPIs:

- **Total Bookings:** 36.28K
- **Average Room Price:** 103.42
- **Average Lead Time:** 85.23 days
- **Cancellation Rate:** 27.57%

These KPIs provide a quick overview of hotel performance, customer planning behavior, and revenue impact.

---

## 📈 Dashboard Features

### 1. Monthly Reservation Trend
- Displays booking growth over time
- Helps identify seasonal demand patterns
- Shows increasing reservations from 2017 to 2018

### 2. Booking by Market Segment
- Compares online, offline, and corporate bookings
- Highlights online platforms as the primary booking source

### 3. Special Requests Analysis
- Shows customer special requests across market segments
- Helps understand customer expectations and service demands

### 4. Lead Time Distribution
- Analyzes how early customers book rooms
- Most guests book between 31–90 days in advance

### 5. Meal Plan Preference
- Visualizes customer meal plan choices
- “Meal Plan 1” is the most preferred option

### 6. Interactive Dashboard Slicers
Users can filter data by:
- Year
- Room Type
- Cancellation Status
